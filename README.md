## 一、这是什么

**赢益共振 v9** 是一套面向**中文期货市场**的波段交易策略，以文华财经（WH6）公式语言实现，
配套一套完整的 **Python 向量化回测引擎**（已与指标落盘代码做过逐点语义一致性校验）。

### 1.1 核心特征

| 维度 | 设定 |
|---|---|
| **市场** | 郑商所：纯碱（SA）、红枣（CJ）、花生（PK）、烧碱（SH） |
| **周期** | **60 分钟**（历史版本曾支持 15 分钟 / 30 分钟 / 日线） |
| **方向** | 双向（多空均可开仓） |
| **信号类型** | 反转 / 逆势（低阈博反弹、高阈博回调） |
| **止损** | 动态阶梯锁盈（移动止盈），非固定止损 |
| **仓位** | 固定比例风险（Fixed-Fractional），单笔风险 = 权益的 **3%** |
| **资金口径** | **每个品种一个独立的 30 万账户**（四个账户互不影响） |

### 1.2 "60D 单品种独立版"这个代号的含义

| 字母 | 含义 |
|---|---|
| `60` | 60 分钟 K 线周期 |
| `D` | D 方案 = 固定比例风险 **3%**（激进档；C 方案为 1%） |
| `单品种独立` | 四个品种各用一个独立 30 万账户，而非合并成一个资金池 |
| `P` | Preferred = ★优选配置（成本闸门关闭 + 出场滑点 0.5 跳） |

### 1.3 为什么是"反转"而不是"追涨杀跌"

策略的前提假设是：**在均线参照下的极端偏离位置，价格有回归中枢的统计倾向**。

- 价格**跌到低阈**（`CEN − 2.5×WV`）→ 挂多单，博反弹
- 价格**涨到高阈**（`CEN + 2.5×WV`）→ 挂空单，博回调

高阈/低阈不是"限制条件"，而是**入场优势区的定义**——只在有价格优势的位置进场。
（数据见 [第八节](#八高低阈开度评估)：把阈值放开会让策略从 +37.3% 掉到 −2.3%。）

## 三、策略原理

### 3.1 三条参考线

所有信号都建立在三条线之上：

```
CEN  = MA(CLOSE, NMID)        # 中枢均线（60 分钟用 NMID=40，即 40 根≈10 个交易日）
WV   = MA(TR, NAV)            # 平均真实波幅（NAV=14），作为"尺度单位"
UPB  = CEN + KB × WV          # 高阈（博回调）
DNB  = CEN − KB × WV          # 低阈（博反弹）
```

`WV` 是整套策略的**度量单位**：止盈目标、止损距离、滑点占比全部用它来表达，
这样同一套参数才能跨品种（纯碱 1200 元/吨、红枣 6800 元/吨）通用。

> **不画高低阈线**：指标不在图上绘制 `UPB/DNB`，避免视觉干扰（用户明确要求）。

### 3.2 信号生成七步

```
① 定位：L ≤ REF(DNB,1)          →  POSLO（下穿低阈）
         H ≥ REF(UPB,1)          →  POSHI（上穿高阈）

② 窗口锁存（本轮最关键的发明）
   WCL  = C > DNB + TGTW×WV  OR  C < DNB − SW0×WV     # 多头窗口的"关闭条件"
   WL   = VALUEWHEN(WCL OR POSLO, POSLO)              # 用价格条件锁存窗口状态
   NEWL = WL AND NOT REF(WL,1)                        # 上升沿 = 新窗口开始

③ 出信号：RAWL = NEWL AND NOT POSHI AND GATE          # 多头信号
           RAWS = NEWS AND NOT POSLO AND GATE          # 空头信号

④ 锚定入场：EL = VALUEWHEN(RAWL, REF(DNB,1))           # 入场价锚 = 上一根的低阈
             WVL = VALUEWHEN(RAWL, WV)                 # 锁定当时的波幅

⑤ 初始止损：R0L = SW0 × WVL ;  S0L = EL − R0L

⑥ 阶梯锁盈：每上移 k×LSTP×R0L（k=1..5）就上抬一次止损线
             SLL = S0L + DYNM × A₁ × (R0L + NK_L × LSTP × R0L)

⑦ 目标位：TGL = EL + TGTW × WVL（TGTW=3.0，即 3 倍波幅）
   持仓维持：HOLD = VALUEWHEN(RAWL OR EXA, RAWL)
   开仓：BUY = RAWL AND NOT REF(HOLD,1)
   平仓：EXL = REF(HOLD,1) AND NOT HOLD
```

### 3.3 三个关键设计（也是三个踩过的坑）

#### ① 价格窗口锁存 —— 解决"持仓期反复重锚"

**问题**：如果每根触及低阈的 K 线都出信号，一轮下跌会连续触发多次开仓请求，
且每次都用**当时的**低阈重新锚定入场价与止损价，导致止损线跟着价格下移而永不触发。

实测：重锚率高达 **85.7%**（几乎每根 K 线都在重锚）。

**解法**：用 `VALUEWHEN`（文华中相当于"取上一次条件成立时的值"）把
「价格条件」变成一个**持续的状态位**（`WL`），只在**上升沿**（`NEWL`）产生一次信号。
一轮下跌只开一次仓，锚点在**整段持仓期内不变**。

效果：重锚率 **85.7% → 0.2%**。

> 文华 WH6 **不支持** `LOOP`/`FOR` 之外的跨周期引用，也没有 `LOOP2`，
> 因此必须用 `VALUEWHEN` 锁存而不是循环。

#### ② 阶梯锁盈（动态止损）—— 解决"被噪音震荡出局"

**问题**：固定止损会被日常噪音打掉。实测在固定止损版本中，
**止损笔数占比 71.4%**，且"被止损后价格又回到原目标位"的比例很高。

**解法**：价格每向上走 `1 × LSTP × R0`（即 1 倍初始风险），
就把止损线整体上抬 `R0 + NK × LSTP × R0`（`NK` = 已触发的档数，最多 5 档）。
止损线**只上移、不下移**。

效果对比：

| 出场结构 | v8（固定止损） | v9（阶梯锁盈） |
|---|---|---|
| 止损笔数占比 | 71.4% | **26.0%** |
| 亏损型出场 | 89.6% | **26.0%** |
| 移动止盈出场 | 0% | **74.0%** |

#### ③ 入场当根止损必须计入 —— 一个约 23% 的口径陷阱

**问题**：约 **23%** 的开仓在**进场那根 K 线之内**就已经击穿了初始止损。
如果回测只在"下一根 K 线"开始检查止损，会系统性高估收益。

修正前后（平均 R）：

| 口径 | 平均 R |
|---|---|
| 不在入场根检查止损（乐观） | 0.914 |
| **计入入场根（悲观，本版采用）** | **0.555** |

本版所有结果均采用**悲观口径**：同一根 K 线内止损与目标同时命中时，**按止损计**。

### 3.4 成本闸门（本版已关闭）

策略内置一个"成本闸门"：

```
GATEW = 0  →  恒开闸（本版采用）
GATEW > 0  →  仅当 成本/WV ≤ GATEW 时才允许出信号（数值越小越严格）
```

关闭原因（详见 [第七节](#七资金使用优化) 与历史报告）：

- 在真实成本下，四品种的 `成本/WV` 只落在 15 分钟 0.26~0.33、日线 0.06~0.13 的**窄区间**，
  闸门实际只能"全开或全关"，没有中间档；
- 15 分钟周期下默认 `GATEW=0.30` 会把 **78 笔信号砍到 3 笔**，收益从 +34.3% 变 −1.4%；
- 三项稳健性检验（横截面 / 增量交易 / 时间切分样本外）均显示"关闭更优"：
  关闭闸门后多出的 **124 笔**交易，加权期望 R = **+0.519**（闸门筛掉的恰恰是赚钱的交易）。

## 四、指标参数完整说明

指标文件：`indicator/赢益共振_v9.XTRD`（GBK 编码，257 行 / 代码行 150 / 114 个变量 / 0 重复）

### 4.1 信号参数

| 参数 | 本版取值 | 含义 | 调参建议 |
|---|---|---|---|
| `NMID` | **40** | 中枢均线周期 | 60 分钟固定 40；30 分钟建议 40；15 分钟用 60；日线用 20 |
| `NAV` | **14** | 波幅均线周期 | 不建议改动 |
| `KB` | **2.5** | 高低阈轨道宽度（倍 `WV`） | **核心参数，不建议放开**（见第八节） |
| `SW0` | **1.25** | 初始止损 = `SW0 × WV` | 越小止损越紧、越易被扫 |
| `DYNM` | **1** | 阶梯锁盈的最先触发档 | 1 = 第一档就上抬止损；0 = 不开启动态止损 |
| `LSTP` | **1.0** | 阶梯步长（倍初始风险） | 每档上抬 1×R |
| `TGTW` | **3.0** | 目标位 = `TGTW × WV` | 3 倍波幅；设为 0 则关闭目标止盈 |
| `GATEW` | **0** | 成本闸门（0 = 关闭） | 建议保持 0 |

> ⚠️ **历史陷阱**：早期版本 `TGTW` 默认值被误设为 `0.5`，导致目标位只有 0.5 倍波幅，
> 几乎所有交易都在触及目标后反向；这是当时收益为负的**致命原因**。本版已修正为 `3.0`。

### 4.2 仓位参数（下单环节，不属于指标公式）

| 参数 | 本版取值 | 含义 |
|---|---|---|
| `CAP0` | **300,000** | 每个独立账户的初始资金（元） |
| `RISK` | **0.03** | D 方案：单笔风险预算 = 当时权益的 3% |
| `MGTOT` | **0.80** | 单笔保证金占用上限 = 当时权益的 80% |
| `MAXLOT` | **100** | 单笔最大手数 |
| `MAXPOS` | **4** | 同时持仓上限（本版单品种独立，实际恒为 1） |
| `COMPOUND` | **True** | 复利：每笔按**当时权益**计算风险预算 |

| 参数 | 取值 | 说明 |
|---|---|---|
| `SHOWP` | 1 | 是否显示"建议手数"标注（1=显示 / 0=隐藏） |

### 5.4 滑点假设（0.5 跳）

**滑点只出现在"出口市价单"上**：

| 环节 | 下单方式 | 滑点 |
|---|---|---|
| 开仓 | 挂锚价（限价单） | **0 跳** |
| 到达目标位 | 挂目标价（限价单） | **0 跳** |
| 止损 / 移动止盈 | 击穿即市价 | **0.5 跳** |

0.5 跳的依据：单笔 20~56 手，**远小于**主力合约 1 跳档位的挂单深度；
条件单多在 1 跳内撮合完成。

**下界参考**：若实盘每次止损都跨满 1 跳，请参考"零闸门 + 1 跳"口径 —
60 分钟四账户合计从 +37.3% 回落到 +32.6% 左右。

### 5.5 仓位管理引擎

**每手最大风险（元）** = `|入场价 − 初始止损价| × 合约乘数` = `SW0 × ATR × 乘数`

**建议手数** = `min( 风险预算 ÷ 每手风险, 资金 × MGTOT ÷ 单手保证金, MAXLOT )`

不足 1 手则**放弃该笔**（不保底开 1 手，避免风险超预算）。

### 5.6 组合推进与结算顺序

同一时点上：**先结算到期持仓**（释放保证金、更新权益）**再开新仓**；
复利模式下，保证金上限按**当时权益**计算，而不是初始资金。

### 5.7 回撤口径：含浮亏（mtm）

**已实现权益** + **在持仓浮盈浮亏**（浮亏按初始止损价截断）→ 求最大回撤。

比只看已实现权益的回撤更接近真实账户体验（持仓期间的浮亏也会让人睡不着）。

## 七、资金使用优化

### 7.1 问题：钱被"保证金上限"卡住了

D 方案的定义是"单笔最大亏损 = 当时权益的 3%"，理论上每笔都该按 3% 风险开足手数。
但诊断发现：**该开的手数根本开不出来**。

原因有两个默认限制：

- `MGTOT = 0.60`：单笔保证金占用不得超过权益的 60%
- `MAXLOT = 50`：单笔最多 50 手

诊断结果（优化前）：

| 品种 | 按 3% 风险应开 | 保证金上限允许 | 实际开出 | 被压制的笔数 | 风险预算只用了 |
|---|---|---|---|---|---|
| 纯碱 | 43.1 手 | 42.5 手 | 38.0 手 | 12/22 | 88.7% |
| 红枣 | 24.0 手 | 23.2 手 | 20.8 手 | 3/8 | 87.8% |
| **花生** | **69.4 手** | **42.8 手** | 42.3 手 | **22/23** | **66.5%** |
| 烧碱 | 17.1 手 | 20.0 手 | 16.1 手 | 4/20 | 93.0% |

**花生 23 笔里有 22 笔被砍手数，实际单笔风险只有 2.00%，而不是 3.00%。**

> 瓶颈差异：纯碱/花生 → 保证金是瓶颈；红枣/烧碱 → 风险预算是瓶颈。

### 7.2 修正方案（动的是"资金上限"，不是"风险"）

| 参数 | 原值 | 新值 | 理由 |
|---|---|---|---|
| `MGTOT` | 0.60 | **0.80** | 单品种同时只持 1 仓，无叠加风险；留 20% 缓冲 |
| `MAXLOT` | 50 | **100** | 纯粹是不必要的天花板 |

> **关键点**：放宽的是"资金占用上限"，**不是"风险"**。
> 每笔该亏多少仍是权益的 3%，只是让原本就该开的仓位真的能开出来。

### 7.3 效果

| 品种 | 风险预算利用率 | 收益率 | Calmar |
|---|---|---|---|
| 纯碱 | 88.7% → **97.5%** | +44.5% → **+47.5%** | 16.72 → 17.04 |
| 红枣 | 87.8% → **95.8%** | +13.9% → **+16.2%** | 6.00 → 7.20 |
| 花生 | 66.5% → **83.2%** | +42.6% → **+56.6%** | 17.26 → **21.95** |
| 烧碱 | 93.0% → **97.3%** | +29.4% → +28.9% | 16.48 → 15.51 |

**四账户合计：+391,297 元 → +447,633 元（多赚 56,336 元），收益率 +32.6% → +37.3%。**

**两个必须如实说明的点**：

1. **烧碱是唯一"负优化"**：它的瓶颈本来就在风险预算（不是保证金），提高上限只让它多开 0.85 手，
   收益反而少 0.5pp、Calmar 从 16.48 降到 15.51。**若偏保守，烧碱可单独保持 60% 上限。**
2. **保证金占用峰值从 60% 升到 78%**，回撤小幅上升（纯碱 5.67%→6.16%、花生 4.16%→4.59%）。
   行情剧烈不利时 78% 占用可能触及追加保证金，不能接受就把 `MGTOT` 调回 0.6~0.7。

## 八、高低阈开度评估

### 8.1 为什么要评估

策略的入场位置由 `KB` 决定。**认为"阈值是一种限制、放开会更好"是常见直觉**，
但数据给出了相反的答案——因此做了一次完整的开度扫描。

### 8.2 开度扫描（60 分钟 · 四品种 · 各 30 万 · D 方案 3% · ★优选）

| 高低阈位置 | 信号数 | 成交 | 胜率 | PF | 期望 R | 四账户收益率 | 回撤 | Calmar |
|---|---|---|---|---|---|---|---|---|
| **均线 ± 2.50 × WV（★最终采用）** | 73 | 73 | **74.0%** | **3.23** | **+0.795** | **+37.3%** | **1.51%** | **24.78** |
| 均线 ± 2.00 × WV（曾评估） | 76 | 76 | 72.4% | 2.40 | +0.641 | +28.1% | 1.95% | 14.40 |
| 均线 ± 1.50 × WV | 72 | 72 | 70.8% | 2.22 | +0.563 | +22.8% | 2.22% | 10.27 |
| 均线 ± 1.00 × WV | 54 | 54 | 68.5% | 2.04 | +0.476 | +14.3% | 1.91% | 7.47 |
| 均线 ± 0.75 × WV | 45 | 45 | 66.7% | 1.86 | +0.400 | +10.1% | 2.16% | 4.71 |
| 均线 ± 0.50 × WV | 35 | 35 | 54.3% | 1.01 | +0.073 | +0.2% | 6.20% | 0.03 |
| 均线 ± 0.25 × WV | 16 | 16 | 18.8% | 0.17 | −0.903 | −7.9% | 9.03% | −0.87 |
| 阈宽 = 0（退化为均线） | 2 | 2 | 0.0% | 0.00 | −1.369 | −1.5% | 1.51% | −1.01 |
| **彻底放开**（阈宽 0 + 取消上下互斥） | **145** | 145 | **52.4%** | **0.96** | **+0.010** | **−2.3%** | **11.48%** | −0.20 |

### 8.3 两条结论

**① 放开是负贡献，且随放开程度单调变差。**

高低阈不是"限制"，它是**入场优势区的定义**：只有跌到低阈才值得博反弹、涨到高阈才值得博回调。
阈值收窄 ＝ 在越来越没有价格优势的位置也进场，于是胜率与赔率同步下滑：

- `2.5 → 2.0`：多 3 笔，但少赚 **9.2pp**
- 彻底放开：信号从 73 笔翻倍到 **145 笔**，但胜率崩到 52.4%、PF 0.96、
  期望 R 仅 **+0.010**（≈ 0）、收益 **−2.3%**、回撤放大到 11.48% —— 手续费与滑点把利润全部吃光。

**② 一处结构性耦合（调参时容易踩）。**

窗口关窗条件 `C > DNB + TGTW×WV` 里含 `DNB (= CEN − KB×WV)`，
当 `KB` 缩到 0 时关窗门槛升到 `CEN + 3×WV`，窗口几乎再也关不上，
信号数反而从 73 笔**塌到 2 笔**。

> 所以"放开阈值"并不单调地等于"信号变多"。
> **改 `KB` 前一定要先看关窗条件的耦合。**

| 参数 | 取值 | 说明 |
|---|---|---|

```
                       当时权益 × 80% ÷ 单手保证金,
                       100 )
不足 1 手 → 放弃该信号
```

指标会在图上直接标注**建议手数**（受 `SHOWP` 控制）。

## 十二、局限与风险

### 12.1 样本与方法

1. **样本期短**：8.5~11 个月，73 笔交易。表中的年化收益率是**短样本外推**，不是可持续预期。
2. **红枣仅 8 笔**：胜率 75.0% / PF 3.28 这类指标统计意义很弱（4 笔盈利就能把胜率拉到 50%~75%）。
3. **主力合约切换**：使用单一主力合约（如 SA2701），未做跨主力合约的拼接与换月处理，
   换月价差未建模。
4. **`KB=2.5` 是经验最优**，不是唯一真理：第八节的扫描显示它是本样本下的最优开度，
   但 2.5 与 2.0 都能盈利，只是收益差 9.2pp。**换品种或换周期建议重新扫一遍。**

### 12.2 成本

5. **滑点是最难估算的一项**：本版假设止损/移动止盈出场只滑 **0.5 跳**。
   若实盘每次跨满 1 跳，四账户收益会从 +37.3% 回落到约 +32.6%。
6. **手续费按公司标准（约交易所 3 倍）**已计入，但**未考虑**交易所临时调整保证金/手续费。
7. **未建模**：涨跌停板无法成交、极端行情跳空、流动性枯竭、夜盘单边行情。

### 12.3 资金与风险

8. **保证金占用峰值已到约 78%**：一旦行情剧烈不利、浮亏扩大，
   可能触及追加保证金通知。不能接受就把 `MGTOT` 调回 0.6~0.7。
9. **D 方案（3% 风险）本身是激进档**：单笔最大亏损可达权益 3%，
   连续 10 笔亏损即回撤约 26%。保守起见请改用 C 方案（1%）。
10. **提高资金上限会同步放大回撤**：优化后纯碱回撤 5.67%→6.16%、烧碱 4.31%→5.07%。
11. **单品种独立 ≠ 分散风险**：四个账户互不影响，但都暴露在同一个商品板块（化工/农产品）的
    宏观冲击下，极端行情下可能同步亏损。

### 12.4 工程

12. **30 分钟周期不建议实盘**：样本短 + 数据为合成（15 分钟合成 30 分钟）+ 对均线周期极敏感
    （`NMID` 20→80 时收益在 +42.3% ~ −5.3% 之间摆动，判定为参数拟合）。
13. **文华公式语言限制**：无 `LOOP2`、无跨周期引用、无数组，
    所有逻辑必须用 `VALUEWHEN` 锁存实现，可读性受限。
