二、高低阈开度：评估与最终选择（维持 KB = 2.5）

v9 的入场位置由两条轨道定义：高阈 UPB = CEN + KB×WV （价格涨到此处挂空、博回调）、低阈 DNB = CEN − KB×WV （价格跌到此处挂多、博反弹）。KB 是轨道宽度系数，原值 2.5。

「放开高低阈」= 把 KB 收窄，让阈值离均线中枢更近、更容易被触及，入场机会更多。 为确认这样做的代价，先做一次开度全网格扫描。

另有一处结构性耦合值得记录（调参时容易踩）：窗口关窗条件 C > DNB + TGTW×WV 里含 DNB（= CEN − KB×WV）， 当 KB 缩到 0 时关窗门槛升到 CEN + 3×WV，窗口几乎再也关不上， 信号数反而从 73 笔塌到 2 笔。所以"放开"并不单调地等于"信号变多"。

三、如何最合理地使用资金

问题：钱被"保证金上限"卡住了

D 方案的定义是「单笔最大亏损 = 当时权益的 3%」。理论上每笔都该按 3% 开足手数， 但实际会发现：该开的手数开不出来。原因有两个默认限制：

  • MGTOT=0.60：单笔保证金占用不得超过权益的 60%。
  • MAXLOT=50：单笔最多 50 手。

最突出的是花生：按 3% 风险该开 69.4 手， 保证金上限只允许 42.8 手 → 实际只开 42.3 手， 风险预算只用了 66.5%（实际单笔风险 2.00% 而不是 3.00%）， 23 笔里有 22 笔都被砍过手数。资金明显没用足。

修正：在 D 方案框架内放宽资金上限

关键认识：这里放宽的不是"风险"，而是"资金占用上限"。 单笔风险预算始终是权益的 3% —— 提高保证金上限，只是让原本就该开的仓位能真正开出来。

五、各品种逐笔交易记录

下面按品种给出每一笔交易的完整记录。一笔完整交易拆为两行： 开仓行（方向 开多 或 开空）与 平仓行（方向 平多 或 平空）。

  • 开多 ＝ 买入开仓，建立多头持仓；平多 ＝ 卖出平仓，了结多头持仓。
  • 开空 ＝ 卖出开仓，建立空头持仓；平空 ＝ 买入平仓，了结空头持仓。
  • 方向列：多系（开多 / 平多）标红色，空系（开空 / 平空）标绿色。
  • 盈亏列：红色为盈利、绿色为亏损（国内期货惯例）。
  • 保证金＝开仓时实际占用的保证金；本笔风险＝按当时权益 3% 计算的最大可亏额度 （＝入场价与初始止损价之差 × 手数 × 合约乘数）。
  • 开仓行与平仓行成对出现，平仓行的「平仓后权益」为该笔了结后的账户权益（复利基数）。

七、必须知道的局限

  • 高低阈 KB=2.5 是经验最优，不是唯一真理：第二节的扫描显示它是本样本下的最优开度， 但 2.5 与 2.0 都能盈利，只是收益差 9.2pp。若换品种或换周期，建议重新扫一遍。
  • 样本期 8~9 个月（2026-01-19~2026-10-09），年化收益率是短样本外推，不能当可持续预期。
  • 红枣只有 8 笔交易，胜率 75.0% / PF 3.28 这类指标统计意义弱。
  • 保证金占用峰值已到约 78%：一旦行情剧烈不利、浮亏扩大，可能触及追加保证金通知。若不能接受，把 MGTOT 调回 0.6~0.7。
  • 提高资金上限会同步放大回撤：优化后纯碱回撤 5.67%→6.16%、 烧碱 4.31%→5.07%。
  • 滑点是最难估算的一项：本配置假设止损/移动止盈出场只滑 0.5 跳，若实际每次跨 1 跳，收益会明显下降。
  • D 方案（3% 风险）本身是激进档：单笔最大亏损可达权益 3%，连续 10 笔亏损即回撤约 26%。
