## 二、交易逻辑

```
参照（均线中枢）   CEN = MA(CLOSE, NMID)
低阈（博反弹）     DNB = CEN - KB*WV        ← 触及此处，挂多单
高阈（博回调）     UPB = CEN + KB*WV        ← 触及此处，挂空单
                    WV  = MA(真实波幅, 14)   ← 波动尺度，跨品种自适应
```

轨道价由**上一根K线收盘**确定，所以可以提前挂限价单，**无未来函数**。

### 新增一：价格窗口锁存

```
WCL := CLOSE > DNB + TGTW*WV  OR  CLOSE < DNB - SW0*WV
WL  := VALUEWHEN(WCL OR POSLO, POSLO)      // 1 = 多窗口开启中
RAWL:= WL=1 AND NOT(REF(WL,1)=1) AND NOT(POSHI) AND GATE
```

**为什么必须加这一层**：如果写成"每根触及低阈的K线都出信号"，持有期间价格会反复触及轨道，
把入场价 `EL` 和波动 `WVL` 一起搬走 —— 止损基价被中途重置。
实测该情形曾占 **85.7%**，使三个周期的期望全部转负（-0.328 / -0.083 / -0.091 ATR）。
改用窗口锁存后，重锚概率降到 **0.2%**，三周期全部转正。

### 新增二：阶梯锁盈动态止损

```
R0  = SW0 * WV            // 一个风险单位，随入场时的波动锁定
S0L = EL - R0             // 初始止损：入场价下方 SW0 倍波动
H1L = REF(HIGH,1) >= EL + 1*LSTP*R0      // 价格向上走出第一档
A1L = VALUEWHEN(RAWL OR H1L, H1L)*(1-RAWL)
NKL = A1L+A2L+A3L+A4L+A5L                // 已锁档数
SLL = S0L + DYNM*A1L*(R0L + NKL*LSTP*R0L)
```

读法：价格每向上走出一档 `LSTP*R0`，止损就上移到该档位，**只上不下**。
一旦走出第一档，止损立刻抬到成本之上 —— 之后的"被止损"实际上是**止盈**。

数学上等价于「以持仓期最高价为锚、最大回吐 SW0 倍波动」的跟踪止损，
但**只用 `VALUEWHEN` 锁存实现**：不需要变量自引用、不需要 `LOOP2`、无未来函数。
（文华官方明确：只有 `LOOP2` 支持自引用，且属 WH8+，WH6 必须用锁存写法。）

## 五、怎么用（一分钟版）

1. 导入指标，按周期改 `NMID`，按品种改 `COSTR`，其余保持默认。
2. 面板显示「闸门：关」→ 本档不做（摩擦成本太高）。
3. 面板显示「低阈附近」→ 在低阈价挂**买限价单**；「高阈附近」→ 挂**卖限价单**。
4. 成交后，红线（或绿线）就是你的止损价；它只会朝有利方向移动。
5. 价格走到目标线（`TGTW` 倍波动）时，指标的出场标记会亮。

## 九、仓位管理（2026-10-11 新增）

### 9.1 方法：固定风险比例法（Fixed-Fractional）

> 目标是让**每一笔交易的最大亏损，都固定在账户权益的同一个百分比**，
> 而不管做的是波动大的红枣还是波动小的烧碱。

```
每手最大风险  = |入场价 − 初始止损价| × 合约乘数 = SW0 × ATR × 合约乘数
风险预算      = 账户资金 × RISKP                （RISKP 默认 1%）
建议手数      = min( 风险预算 ÷ 每手最大风险 , 账户资金×MGTOT ÷ 单手保证金 , 50 )
```

* 入场价与初始止损价由指标自己给出（`EL` 与 `S0L`/`S0S`），止损距离天然等于 `SW0×ATR`，
  所以不需要再额外估波动率——**波动大的品种自动减手，波动小的自动加手**。
* 第二项是**保证金上限**（`MGTOT`=60%），防止四品种同时开仓时把仓位打满。
* 建议手数为 0 表示**连 1 手都超出风险预算**——此时按纪律应当放弃该信号，而不是硬开 1 手。

### 9.5 资金门槛（重要）

`RISKP=1%` 意味着"每笔最多亏 1%"，而每手最大风险是大致固定的，
所以**资金太小会导致部分品种连 1 手都开不起**：

| 初始资金 | 60分钟 开仓/跳过 | 日线 开仓/跳过 |
|---|---|---|
| 10 万 | 54 / 0 | **10 / 9** ← 日线有 9 笔被放弃 |
| 20 万 | 54 / 0 | 18 / 1 |
| **30 万** | **54 / 0** | **19 / 0** |
| 50 万 | 54 / 0 | 19 / 0 |

做这 4 个品种、按 1% 风险，**30 万是可以让所有信号都可执行的最低水位**（日线烧碱每手最大风险约 1,500 元）。

### 9.6 回撤节流（结论：不需要）

测试了「回撤 ≥2%/3%/5%/8% 时把风险预算砍半」：
本策略在 1%~3% 档位的实际回撤只有 3%~4%，节流几乎不触发；勉强触发时因为砍掉了恢复行情的仓位，
收益反而略微下降。**本策略的风险来源是"单笔亏损"而不是"连续亏损"，
所以用「单笔风险上限 + 保证金上限」两道闸就够了，不必加回撤节流。**

## 十二、闸门开闭与滑点设置的专项优化（2026-10-11 深夜）

> 本节回答一个问题：**怎样"合理地开闭闸门、设置滑点"，才能把收益进一步提高？**
> 结论：把闸门**关掉**（收益提升的主要来源），并把出场滑点从 1 跳修正为 0.5 跳（次要来源）。

### 12.1 两个改动

| # | 项目 | 原来 | 现在 | 性质 |
|---|---|---|---|---|
| ① | 成本闸门 `GATEW` | 0.30（出厂默认） | **0.0（关闭）** | 零假设、零成本，收益提升主要来源 |
| ② | 出场滑点 | 1 跳 | **0.5 跳** | 把"每次止损都被打 1 跳"的保守假设修正为现实中枢 |

其余参数（`KB=2.5 SW0=1.25 DYNM=1 LSTP=1.0 TGTW=3.0`）与仓位口径（30 万本金、复利、C=风险 1% / D=风险 3%）**完全不变**。

### 12.2 为什么关闭闸门

**（1）闸门在真实成本下只能"全开或全关"，没有中间档。**

四品种的 `COSTW = 往返成本 ÷ 价格窗口` 分布很窄：

| 周期 | COSTW 中位区间 | 闸门可调性 |
|---|---|---|
| 15 分钟 | 0.26 ~ 0.33 | 无（GATEW < 0.26 全拦，> 0.33 全放） |
| 30 分钟 | 0.18 ~ 0.25 | 无 |
| 60 分钟 | 0.13 ~ 0.20 | 无 |
| 日线 | 0.06 ~ 0.13 | 无 |

后果：**15 分钟在默认 `GATEW=0.30` 下，78 笔信号只剩 3 笔，收益从 +34.3% 变成 −1.4%。**

**（2）闸门拦掉的恰恰是赚钱的交易。**

把"闸门=0 相对 0.30 多出来的交易"单独统计 —— 这些正是被拦下的：

* 合计 **124 笔**，按笔数加权**期望 R = +0.519**
* 逐组看几乎全为正（16 组中仅 1 组为负，且只有 2 笔）

**（3）三项稳健性检验**

| 检验 | 结果 |
|---|---|
| 横截面一致性（4 周期 × 4 品种） | 关闭更优 **9** 组 / 默认更优 3 组 / 持平 4 组；30 分钟 4/4 全部"关闭更优" |
| 增量交易质量 | 124 笔增量加权期望 R = **+0.519** |
| 时间切分样本外（前 60% / 后 40%） | 样本外组内均值：关闭 **+0.748** vs 默认 +0.440 —— 样本外同样占优 |

结论：关闭闸门不是过拟合，而是"闸门这个设计在本策略上方向就是错的"。

### 12.3 为什么滑点是 0.5 跳

本策略的成交方式决定了滑点只出现在**出口市价单**上：

* **开仓**：在锚价位（低阈/高阈）**挂限价单**等价格回来 → 滑点 0
* **到达目标**：在目标价位**挂限价单** → 滑点 0
* **止损 / 移动止盈**：条件单触发后**市价平仓** → 这才是唯一有滑点的地方

0.5 跳的三条依据：

1. **规模远小于盘口深度**：30 万本金、C 方案下单笔约 20~40 手，
   而四品种主力合约在 1 跳档位的挂单深度普遍在数十至数百手 → 吃穿 1 跳并非常态
2. **成交机制**：郑商所条件单触发后下单，多数在 1 跳内撮合完成 → 0 跳与 1 跳各占相当比例
3. **方向性偏保守**：止损单触发时市场正朝不利方向运动，滑点确实偏向不利，
   所以取 0.5 跳已经是"偏乐观的中枢估计"，而非理想上界（0 跳）

**同时保留 1 跳的保守结果**：若实盘每次止损都跨 1 跳，请以"关闭闸门 + 滑点 1 跳"的数值为准。

### 13.1 现象

### 13.2 根因

### 14.2 状态面板瘦身 —— 解决「文字把 K 线撑得展不开」

**问题**：原面板 10 行，第 k 行的位置是 `HIGH + SRNG*0.05k`（k=1..10），
最顶那行到 `HIGH + 0.95×SRNG`。而 `SRNG = MAX(HHV(HIGH,120)-LLV(LOW,120), CLOSE*0.01)`
是 **120 个周期的振幅**，通常比单根 K 线高度大十几倍 —— 相当于在最后一根 K 线上方
硬撑出近一整个波段的空间，K 线自然被压成一条线。

**改法**：

| 项目 | 原 | 现 |
|---|---|---|
| 面板行数 | 10 行（SY1~SY10） | **7 行（SY1~SY7）** |
| 行距 | `SRNG*0.10` | **`SRNG*0.035`** |
| 面板顶高 | `HIGH + 0.95×SRNG` | **`HIGH + 0.245×SRNG`**（**降 74.2%**） |
| 总开关 | 无 | **新增 `SHOWPNL`**（1=显示 / 0=整段隐藏，K 线完全展开） |
| 成本/波动比例行 | 有 | **删除**（`GATEW=0` 后闸门恒开，该值不再参与决策，且常显示成 0.xx 像 0） |

> 想彻底不要面板：把面板段第一行的 `SHOWPNL:=1;` 改成 `SHOWPNL:=0;` 即可。

### 18.2 高低阈是什么

```
高阈 UPB = CEN + KB*WV     ← 价格涨到此处挂空，博回调
低阈 DNB = CEN - KB*WV     ← 价格跌到此处挂多，博反弹
CEN = MA(CLOSE, NMID)      KB = 轨道宽度系数（原 2.5）   WV = MA(TR, NAV)
```

"放开高低阈"＝把 `KB` 收窄，让阈值更贴近均线中枢、更容易被触及。

### 18.4 两条重要结论

**(1) 放开越彻底，效果越差 —— 且丢的是策略的核心优势**

高低阈**不是"限制"，它是入场优势区的定义**：只有跌到低阈才值得博反弹、涨到高阈才值得博回调。
阈值收窄＝在越来越没有价格优势的位置也进场：

* `KB` 2.5 → 2.0：胜率 74.0%→72.4%，期望 R +0.795→+0.641，收益 **+37.3% → +28.1%**；
* 2.0 → 1.0：收益再腰斩到 +14.3%；
* **彻底放开**（阈宽归零 + 取消上下互斥）：信号从 73 笔翻倍到 **145 笔**，但胜率崩到
  **52.4%**、PF **0.96**、收益 **−2.3%**、回撤放大到 **11.48%** —— **手续费与滑点把利润全部吃光**。

**(2) 一处结构性耦合（工程上必须知道）**

窗口关窗条件 `C > DNB + TGTW*WV` 里含 `DNB（= CEN − KB*WV）`，代入得
`C > CEN + (TGTW − KB)*WV`。**KB 缩到 0 时关窗门槛升到 `CEN + 3*WV`，窗口一旦打开
几乎再也关不上**，`NEWL` 上升沿几乎不再出现 → 信号数反而从 73 笔**塌到 2 笔**。
所以"放开"并不单调地等于"信号变多"，必须先取消上下阈互斥才有 145 笔。
